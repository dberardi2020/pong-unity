## Concept
A simple 2D Pong clone. First Unity project — primary goal is learning Unity fundamentals, not shipping a novel game.

## Goals
- Understand Unity's component system (GameObjects, MonoBehaviours, lifecycle methods)
- Get comfortable with 2D physics, input handling, and scene management
- Establish a working terminal-first dev workflow with Unity

## Scope (v1)
- Two paddles (player vs AI or player vs player)
- Ball with basic physics/bounce
- Score tracking
- Win condition

## Out of Scope (v1)
- Menus, sound, visual polish — add only after core mechanics work

## Stack
- Unity 6000.3.11f1
- C# scripts under `Assets/Scripts/`
- Project root: `~/Projects/Pong/`
