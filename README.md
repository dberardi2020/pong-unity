# Pong

A single-player 2D Pong clone built in Unity 6. First project — primary goal is learning Unity fundamentals.

## Gameplay
- Player controls the left paddle (W/S or arrow keys)
- AI controls the right paddle with configurable difficulty
- First to the target score wins

## Stack
- Unity 6000.3.11f1
- C# / Unity 2D physics

## Status
In progress — core mechanics not yet complete.
