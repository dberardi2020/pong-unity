# Pong

A 2D single-player Pong clone built in Unity 6.3. You control the left paddle; an AI controls the right. First to 5 points wins.

First game from [Round To It Studio](https://github.com/dberardi2020/RoundToItStudioHQ). Primary goal is learning Unity fundamentals through a complete, working game.

---

## Stack

- Unity 6.3 LTS (6000.3.14f1)
- C# / MonoBehaviour
- Unity 2D Physics (Rigidbody2D, Collider2D)
- TextMeshPro (UI)

## Running the Project

1. Clone the repo
2. Open Unity Hub > Add project from disk > select this folder
3. Open with Unity 6.3 LTS
4. Open `Assets/Scenes/Game.unity`
5. Press Play

## Controls

| Key | Action |
|-----|--------|
| W / Arrow Up | Move paddle up |
| S / Arrow Down | Move paddle down |
